# 随 Skill 打包离线菜谱快照

发布 Skill 时，打包一份固定上游版本的 HowToCook 菜谱 Markdown 和由其生成的结构化索引，并记录来源仓库及对应 commit。运行时不要求用户联网、安装数据库或另行克隆 HowToCook；菜谱更新随本项目的新版本发布。

打包内容不包括上游 Git 历史、网站构建文件和其他开发资源。2026-08-15 对 HowToCook `master` 源码快照的测量结果为：369 个菜谱 Markdown，共 776,772 字节；整个源码快照解压后也只有 1,166,412 字节。因此，菜谱文本和索引不会成为 Skill 的显著体积负担。
