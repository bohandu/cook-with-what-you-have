# 在首个版本中支持整餐搭配

当用户表达的是安排一顿饭而不是选择单道菜时，系统确认本次用餐人数和希望制作的菜品数量，然后返回三个完整的整餐搭配方案。每个方案先简要展示所含菜品、整体匹配程度、缺少的关键食材和大致制作负担；用户选中方案后，再忠实展示其中各道 HowToCook 原菜谱。

整餐方案必须整体遵守过敏原和忌口，并根据现有食材利用率、缺失关键食材的并集、菜品之间的主要食材与做法差异进行排序。较弱的补位方案可以用于补足三个候选，但必须明确说明不足。该功能限于当前一餐，不扩展为周计划或营养治疗方案。

在用户没有素食限制或明确指定菜品类型时，两道菜的方案可以将“一荤一素”作为软排序偏好，以增加搭配差异；它不是硬性规则。若两道素菜能更好地利用现有食材、减少缺失项或满足用户偏好，应当排在一荤一素方案之前。
